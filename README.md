# Cat Robert – landing pages

Static site for Vercel. No build step.

- `/first-home` – First-time buyer affordability calculator (lead magnet #2)
- `assets/config.js` – **the only file you normally edit**: phone, licence #, pixel ID, lead URL, current rate.

Deploy: push this folder to GitHub → import the repo in Vercel (Framework preset: "Other", no build command).
